# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 4.x (latest minor) | ✅ |
| < 4.0 | ❌ |

## Reporting a vulnerability

Please don't open a public issue.

Report it privately on GitHub (Security tab → "Report a vulnerability"), or email ajaythorat988@gmail.com.

You'll get a reply within 5 working days. Once a fix is released, we publish an advisory and credit you, unless you'd rather stay anonymous.

## In scope

- Code execution, path traversal or command injection through a scanned project's files
- Leaking stored API keys or tokens
- DevCompass changing files beyond what a command documents
